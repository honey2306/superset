五色分工分析 · v4 (Pink Signature)

粉是 Dracula 的 signature,不能不见。但也不能到处都是。 问题的正确解法不是"粉多"或"粉少",而是把粉放在它天然属于的位置 —— 小面积、高频次、语义重的点睛处;把大面积的选中/hover 底色让给更沉稳的紫灰。 这份分析先看 Superset 里 bg-primary vs bg-accent 的实际使用频次,再决定每个 token 该穿什么颜色的衣服。

为什么这次要重新分工

v2:accent = 粉,大面积选中底色都是粉 → 每次点击一整块粉,吵、廉价。
v3:accent = 紫灰,但粉被撤到只剩 chart 和小徽章 → Dracula 的辨识度也丢了(用户反馈"粉占比太少")。
v4:重新看代码。bg-accent 用了 140 处(选中/hover),bg-primary 用了 21 处(CTA/focus/workspace 选中)。 粉自然应该在 primary —— 面积小、频次高、语义重、每次都是招牌色在最重要的位置闪一下,这才是 Dracula 该有的表达。

规律很清楚:用户 UI 里的"点睛色"平均每个页面出现 1–3 次,面积总占 UI 的 < 3%,但每次都要被立刻看见。 这就是粉色该做的角色。而"选中态/hover"每次可能占据 20%+ 屏幕面积,必须让给沉稳色。
