2 · 完整问题清单(8 项)

Audit findings

#问题根因修法 (v3)
1 选中态"粉底黑字"廉价 accent = #d47cb0,accent-foreground = 深黑,配合 sidebar 大面积选中很吵 accent → #5a5f85 低饱和紫;accent-foreground → #f2f4ff 亮白
2 accent 和 highlight 都是粉,语义重叠 accent (#d47cb0) 和 highlight (#ff8fd1) 同色相,一个用于"选中"、一个用于"品牌 PRO 徽章",看不出区别 accent 撤出粉色;粉色保留给 highlight / chart1 装饰用途
3 input 与 muted 完全同色 (#3f4560) 两个 token 语义不同(可输入 vs 次要底色),同色时看不出输入框边界 input → #464b68 略浅一档,提示"可输入"
4 border 对比不足 border (#4c5075) 在 card (#3a3e56) 上对比度 ~1.4,分割线糊 border → #525777,对比度提到 ~1.7
5 白色不统一(UI 冷白 vs terminal 暖白) foreground #f2f4ff、terminal white #f2f4ff、但 destructiveForeground 仍是 #f8f8f2 暖白 全部统一到 #f2f4ff
6 primary-foreground 太黑 primaryForeground = #1a1b26,和整个 theme 家族的底色 #2f3244 明显不同源 primaryForeground → #1e1e2e,和 background 家族更协调
7 terminal red 提亮后色相偏粉 v2 把 red 从 #ff5555 拉到 #ff7c7c,亮度上去了但饱和度掉了,和 destructive 分不清 terminal red 回到 #ff6e6e(Dracula 官方 bright red 色系);destructive UI 色保持 #ff7c7c 更亮以突出
8 highlightForeground 不一致 highlightForeground = #282a36 (原 background),但 background 已改为 #2f3244 highlightForeground → #1e1e2e,与 primaryForeground 一致
