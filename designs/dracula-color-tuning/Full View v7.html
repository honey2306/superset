你的反馈揭示了一个物理问题:整体基底是冷调蓝紫 (#2f3244, hsl 233°),任何粉紫 accent 上大面积都会因为色相冲突发浑。这不是调色号能解决的,是方向错了。
回到 Dracula 官方:官方主题的 selected line 是 #44475a 蓝灰,粉从来不做大面积底。粉在 Dracula 语言里是"关键字/字符串"级别的小色块。
v7 的解法:accent 回归 蓝灰 #4c5075(Dracula 官方 selected 提亮版),粉做高密度小尺寸点缀 —— 每屏 15+ 处,但没有一处占大面积。粉的存在感靠"密度"不靠"面积"。

为什么这次会对:Dracula 官方本来就是这个逻辑。你看 VS Code 的 Dracula:选中行是蓝灰,粉在字符串、注释、关键字里点缀。整个主题读起来是"冷底 + 粉/绿/紫的高频小色块",没有大面积粉底。这是它 15 年不过时的原因。

之前 v2 → v6 一直在往"粉紫底"跑,是我一次次背离 Dracula 的语法在解答你的反馈。v7 把它拉回来。
