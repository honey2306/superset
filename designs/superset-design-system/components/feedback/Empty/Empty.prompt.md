Empty-state block. Icon in a soft halo, single title, optional description, one CTA.

```jsx
<Empty
  iconName="branch"
  title="还没有 workspace"
  description="从 GitHub 克隆一个仓库,或用当前目录开始"
  action={<Button variant="primary">Add repository</Button>}
/>
```

Rules: one primary CTA max. Never stack icons or add secondary art. Copy stays factual, not cheerful.
