Dense data table.

```jsx
<Table>
  <THead>
    <TR><TH>Branch</TH><TH mono align="end">Ahead</TH><TH mono align="end">Behind</TH></TR>
  </THead>
  <TBody>
    <TR active><TD>feat/kro</TD><TD mono align="end">3</TD><TD mono align="end">12</TD></TR>
  </TBody>
</Table>
```

Numeric columns use `mono` + right-align so eyes track down the column.
