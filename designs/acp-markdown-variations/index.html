useSlashCommands 概览

useSlashCommands 是 Chat interface 里驱动 斜杠命令菜单的核心 hook。它订阅当前 session 的 availableCommands,把编辑器里的 /<query> 前缀转成一个可导航的 candidates 列表,并把选中的命令 插回 Tiptap 文档。

能力清单

  • 命令发现 — 从 session meta 里读 availableCommands,包含内置和项目 skill
  • 模糊匹配 — 基于当前 query 计算候选,忽略大小写、支持 kebab-case 中缀匹配
  • 键盘导航 — ↑ / ↓ 移动高亮,Enter 或 Tab 确认,Esc 关闭
  • Tiptap 集成 — 通过 SlashCommandNode 把选中命令替换为不可编辑的 chip
  • 参数占位 — 命令支持参数占位,插入后自动把光标停在参数位
  • 状态解耦 — 菜单打开/关闭由外部 state 驱动,hook 不管 UI 只出数据

返回类型

核心签名如下,data-only 输出,UI 完全在调用方组装:

const slash = useSlashCommands({

值不值得抽到 packages?

短答:暂时不值得。原因:

  1. 目前只有 desktop 一处调用方
  2. hook 里的 Tiptap 依赖会把 packages/chat 的包体积拉大 ~180kb
  3. 命令来源(session meta)是 desktop 特有的 tRPC 通道,抽走之前得先抽 protocol

反过来,抽到 apps/desktop 内部的 shared hooks 目录是合理的 —— 也就是从当前 co-located 位置往上挪一层,让 Composer 和未来的 CommandPalette 都能用。
