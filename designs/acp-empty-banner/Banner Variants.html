ACP Empty · Banner Variants 五版对比 · 大字字体探索
Agent name
01 ANSI Shadow · Aurora Claude Code CLI 官方启动风格 · 渐变

				

				
6 行厚实块字模,pink → purple → cyan 斜向渐变。Claude Code、Codex CLI 启动横幅都是这套字体,信息量高但依旧精致。

			

		


		

			
02 ANSI Shadow · Solid 纯单色版

			

				

				

				
同字模,只用 --acp-pink 单色。比 01 更克制、终端感更强,和 boot log 色阶更统一。

			

		


		

			
03 Slant · Mono 斜体 · 速度感

			

				

				

				
5 行 figlet Slant 字体。字重轻、笔画细,像素点感更弱,类似 CLI 里 figlet -f slant 的效果。

			

		


		

			
04 Small · Compact 4 行紧凑

			

				

				

				
只有 3 行的半格块字体,极简且省垂直空间。适合窄 pane 或希望大字不抢镜的场景。

			

		


		

			
05 ANSI Shadow · Neon Outline 描边 + 光晕

			

				

				

				
同 01 字模,CSS text-shadow 制成霓虹描边 + 外发光。视觉存在感最强,适合更"品牌化"的启动屏。

			

		

	


	

		字模数据在 fonts.js,渲染逻辑在 render.js。切换顶部 Agent name 会同步刷新所有 5 版横幅。
