# Preset icon sources

- `deepseek.png` is the DeepSeek whale glyph from the official site favicon at
  <https://www.deepseek.com/favicon.ico>, converted from ICO to PNG for the
  bundled preset icon set (retrieved 2026-08-18).
- `myflicker.png` is the user's own MyFlicker icon uploaded through Quick Add.
  It was read from the local terminal preset settings and resized from 512 ×
  512 to 256 × 256 with metadata stripped for the bundled asset.
